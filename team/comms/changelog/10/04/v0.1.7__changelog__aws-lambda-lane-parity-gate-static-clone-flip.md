# Changelog — AWS Lambda deploy lane, the sgit parity gate, and the static-clone flip

**version** v0.1.7 (repo tag at time of writing) · **date** 2026-10-04 · **branch** `dev`

## What changed

1. **AWS Lambda deploy lane** (`deploy-aws-lambda.yml` + `deploy-aws__{dev,main,prod}.yml`, `deploy/docker/`, `deploy/aws/`, `tests/deploy/`): one API-only image, three stage stacks mirroring the origin repo's three User Lambdas, OIDC-only auth, smoke + parity gates after deploy, CloudFront enabled check. Skips deploy until `AWS_DEPLOY_ROLE_ARN` is set. Not yet run against AWS.
2. **The sgit parity gate** (`tests/regression/`, `regression-parity.yml`): five CLI-driven scenarios, invariants on one endpoint, parity between legacy and new.
3. **Static-clone conformance test flipped**: `test__cli_clone_stops_at_batch` → `test__cli_clones_from_a_static_host`. sgit-ai 0.17.0 (3 Oct) clones from a static host with GETs only.

## Which tests SHOULD break (good failures)

| Test | Breaks when | Why that is good |
|---|---|---|
| `test__cli_clones_from_a_static_host` | a CLI release drops the static transport, or `vault/` is re-published without regenerating `bare/` | the published projection must stay a complete read endpoint |
| `tests/regression` parity | the new API's behaviour differs from the legacy API on any scenario | that is a behaviour change, which the Villager pack forbids |
| `tests/deploy` smoke | a deployed stage stops answering health / OpenAPI / a vault round-trip | the deployment is broken |

## Which tests should NOT break (bad failures)

- `test__credential_tier_is_not_in_the_git_index` — a credential tier was committed: security incident.
- The original 6 unit tests, the other 4 conformance tests.
- `deploy-aws-lambda.yml` jobs before `deploy` — those run without any AWS access; a failure there is a repo defect.

## API surface impact

None. No API code lives in this repo yet; the image serves the pinned origin package. The parity gate exists precisely so that the first commit that *does* change the surface is caught.
