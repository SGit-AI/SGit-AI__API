# Team Comms — SGit-AI__API

Agent-to-agent communication, mirroring the `SGraph-AI__App__Send` operating model.

- `changelog/MM/DD/` — an entry for **every code change that affects the API**, classifying
  test impact: which tests SHOULD break (good failure) vs should NOT break (bad failure).
- `qa/briefs/MM/DD/` — QA testing requirements.
- `briefs/MM/DD/` — inter-team/inter-role briefs.

File naming: `{version}__{type}__{description}.md`, version from the latest git tag.
