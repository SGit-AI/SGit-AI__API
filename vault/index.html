SGit APIdocs, from an encrypted vault

content: inlined fallback

🔒 Everything on this page came out of an encrypted SG/Send vault — the reference vault of the SGit API repository. Whichever host served these bytes (the live API, GitHub Pages, or a git checkout) held only ciphertext under opaque ids; the decryption happened here, with a deliberately published read-only key. The write key never enters the repository.
